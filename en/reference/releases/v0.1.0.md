# UMC v0.1.0

The first UMC release provides a Linux x86_64 GNU build of the Universal Minecraft Core.

## Included

- Vanilla Minecraft Java Edition version metadata, downloads, integrity checks, isolated instances, and offline launch.
- Rust SDK, CLI, newline-delimited JSON-RPC, and local Linux daemon over a private Unix socket.
- Persistent install tasks with progress events, cancellation, retry, timeout, concurrency limits, and restart recovery.
- Java compatibility detection and opt-in managed Mojang runtime installation.
- Process status, logs, stop, and state recovery after daemon restart.

## Install

::: warning This build has been withdrawn

The v0.1.0 release is no longer published, so there is no archive to download. Build from source
using the [installation guide](../../guide/install).

:::

## Scope and limitations

- This release targets Linux x86_64 GNU. Windows and macOS remain planned ports.
- Launch is explicit offline mode. Microsoft authentication and authenticated online play are not implemented.
- Mod loaders and modpack installation are not included.
- The release is unsigned; verify the published SHA-256 checksum before unpacking.
