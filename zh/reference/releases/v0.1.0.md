# UMC v0.1.0

首个 UMC 版本提供 Universal Minecraft Core 的 Linux x86_64 GNU 构建。

## 包含内容

- 原版 Minecraft Java Edition 版本元数据、下载、完整性校验、隔离实例和离线启动。
- Rust SDK、CLI、换行分隔 JSON-RPC，以及基于私有 Unix Socket 的本地 Linux 守护进程。
- 持久化安装任务，支持进度事件、取消、重试、超时、并发限制和重启恢复。
- Java 兼容性检测和可选的 Mojang 托管运行时安装。
- 进程状态、日志、停止，以及守护进程重启后的状态恢复。

## 安装

::: warning 此构建已撤回

v0.1.0 发布包已不再提供，因此没有可下载的压缩包。请按[安装说明](../../guide/install)从源码构建。

:::

## 范围与限制

- 本版本目标为 Linux x86_64 GNU。Windows 和 macOS 仍是计划中的移植。
- 启动为显式离线模式。Microsoft 认证和需要认证的在线游戏尚未实现。
- 不包含模组加载器和整合包安装。
- 发布包未签名；解压前请校验发布的 SHA-256 校验和。
